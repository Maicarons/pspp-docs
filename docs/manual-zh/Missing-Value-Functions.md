#### 7.7.4 缺失值函数

缺失值函数接受各种数值参数并产生各种类型的結果。除非下面另有说明，这些函数内表达式参数的正常求值规则适用。特别是，数值型变量的用户缺失值会被转换为系统缺失值。

Function: __**MISSING** _( expr)_

当 expr 只是数值型变量的名称时，如果该变量具有系统缺失值或是用户缺失值，则返回 1。对于任何其他值，返回 0。如果 expr 采用其他形式，则当值为系统缺失值时函数返回 1，否则返回 0。

Function: __**NMISS** _( expr [, expr]…)_

每个参数必须是数值表达式。返回列表中系统缺失值的数量，列表可以包含使用 `var1 TO var2` 语法的变量范围。

Function: __**NVALID** _( expr [, expr]…)_

每个参数必须是数值表达式。返回列表中非系统缺失值的数量。列表可以包含使用 `var1 TO var2` 语法的变量范围。

Function: __**SYSMIS** _( expr)_

如果 expr 具有系统缺失值，则返回 1，否则返回 0。

Function: __**VALUE** _( variable)_
Function: __**VALUE** _( vector(index))_

阻止变量或向量元素的用户缺失值被转换为系统缺失值，并始终产生其实际值，无论它是有效值、用户缺失值还是系统缺失值。
