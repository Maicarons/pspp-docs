#### 6.7.1 变量的属性

每个变量都有若干属性，包括：

**名称**

一个标识符，最长 64 字节。每个变量必须具有不同的名称。参见 [Tokens](Tokens.md)。

某些系统变量名以 ‘$’ 开头，但用户自定义变量的名称不能以 ‘$’ 开头。

变量名的最后一个字符不应是 ‘.’，因为当成其为行末的最后一个记号时，该标识符会被误解：`FOO.` 会被拆分为两个独立的记号 ‘FOO’ 和 ‘.’，表示命令结束。参见 [Tokens](Tokens.md)。

变量名的最后一个字符不应是 ‘_’，因为某些此类标识符被 PSPP 过程用于特殊用途。

与所有 PSPP 标识符一样，变量名不区分大小写。PSPP 在输出时以变量在输入中定义时的大小写形式显示变量名。

**类型**

数值型或字符串型。

**宽度**

（仅字符串变量）宽度不超过 8 个字符的字符串变量称为 _short string variables_（短字符串变量）。在少数不允许使用 _long string variables_（长字符串变量，即宽度大于 8 的变量）的场合中，可以使用短字符串变量。

**位置**

字典中的变量按特定顺序排列。可以使用 `DISPLAY` 显示此顺序：参见 [DISPLAY](DISPLAY.md)。

**初始化**

可以为每个个案重新初始化为 0 或空格，也可以保留其现有值。参见 [LEAVE](LEAVE.md)。

**缺失值**

可选地，最多可将三个取值、一个取值范围，或一个特定取值加一个范围指定为 _user-missing values_（用户缺失值）。此外还有一个 _system-missing value_（系统缺失值），当某个观测没有其他明显取值时会被赋给该观测。含缺失值的观测会自动被排除在统计或分析之外。用户缺失值是真实的数据取值，而系统缺失值根本不是一个取值。参见 [Missing Observations](Missing-Observations.md)。

**变量标签**

描述变量的字符串。参见 [VARIABLE LABELS](VARIABLE-LABELS.md)。

**值标签**

可选地，将变量的每个可能取值与一个字符串关联。参见 [VALUE LABELS](VALUE-LABELS.md)。

**打印格式**

显示宽度、格式，以及（对数值变量）小数位数。该属性不影响数据的存储方式，只影响显示方式。例如：宽度为 8，小数位数为 2。参见 [Input and Output Formats](Input-and-Output-Formats.md)。

**写入格式**

与打印格式类似，但由 `WRITE` 命令使用（参见 [WRITE](WRITE.md)）。

**测量级别**

以下之一：

名义（Nominal）

名义变量的每个取值代表一个不同的类别。可能的类别是有限的，且通常有值标签。类别间的顺序不重要。政党、美国各州、是/否选择都属于名义变量。数值型和字符串型变量都可以是名义的。

有序（Ordinal）

有序变量同样代表不同的类别，但其取值按照一定的自然顺序排列。李克特量表（例如从强烈不同意到强烈同意）是有序的。归入区间的数据（例如年龄段或收入段）是有序的。数值型和字符串型变量都可以是有序的。字符串取值按字母顺序排序，因此从 A 到 F 的字母等级会按预期排列，但 `poor`、`satisfactory`、`excellent` 则不会。

标度（Scale）

标度变量是指其差值和比值都有意义的一类变量。它们通常是带有自然单位的取值，例如以年计的年龄、以美元计的收入，或以英里计的距离。只有数值变量才是标度变量。

由 `COMPUTE` 及类似转换创建、或从外部来源获取等的变量，最初具有未知的测量级别。任何读取该数据的过程随后会赋予一个默认测量级别。PSPP 可以在不读取数据的情况下赋予某些默认值：

  * 如果是字符串变量，则为名义。
  * 如果变量具有 WKDAY 或 MONTH 打印格式，则为名义。
  * 如果变量具有 DOLLAR、CCA 至 CCE，或时间/日期打印格式，则为标度。

否则，PSPP 会读取数据并根据其分布决定：

  * 如果所有观测都缺失，则为名义。
  * 如果一个或多个有效观测为非整数或负数，则为标度。
  * 如果没有有效观测小于 10，则为标度。
  * 如果变量有 24 个或更多不同的有效取值。数值 24 为默认值，可进行调整（参见 [SET SCALEMIN](SET.md#SET-SCALEMIN)）。

最后，如果上述都不成立，PSPP 将变量赋为名义测量级别。

**自定义属性**

名称与取值之间的用户自定义关联。参见 [VARIABLE ATTRIBUTE](VARIABLE-ATTRIBUTE.md)。

**角色**

变量在图形用户界面对话框中预期的用途角色。参见 [VARIABLE ROLE](VARIABLE-ROLE.md)。
