## 10 合并数据文件

本章介绍用于将系统文件、便携文件以及已打开的数据集中的数据合并，以构成一个新的活动数据集的命令。这些命令可通过以下方式合并数据文件：

  * `ADD FILES` 交错或追加来自各输入文件的个案。它用于具有公共变量、但个案集合不同的输入文件。
  * `MATCH FILES` 将多个输入文件中相匹配的个案的数据合并在一起。它用于具有公共个案、但每个个案信息不同的输入文件。
  * `UPDATE` 用一组事务文件中的数据更新主数据文件。事务数据文件中的每个个案会修改主数据文件中与之匹配的个案，若找不到匹配的个案，则添加一个新的个案。

这些命令共享其大部分语法，下文将先描述这些共性语法，然后分别用一节描述每个命令特有的语法与语义。

| • 合并文件的通用语法 |  |  |
| --- | --- | --- |
| • ADD FILES |  | 交错来自多个文件的个案。 |
| • MATCH FILES |  | 合并来自多个文件的个案。 |
| • UPDATE |  | 使用事务数据更新个案。 |
