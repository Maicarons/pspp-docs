#### 16.4.1 矩阵表达式

许多矩阵命令使用表达式。矩阵表达式可以使用下列运算符，按运算符优先级从高到低列出。在同一优先级内，运算符按从左到右的顺序结合。

  * 函数调用 `()` 与矩阵构造 `{}`
  * 索引 `()`
  * 一元 `+` 和 `-`
  * 整数序列 `:`
  * 乘方 `**` 和 `&**`
  * 乘法 `*` 和 `&*`，以及除法 `/` 和 `&/`
  * 加法 `+` 和减法 `-`
  * 关系运算符 `< <= = >= > <>`
  * 逻辑 `NOT`
  * 逻辑 `AND`
  * 逻辑 `OR` 和 `XOR`

可用的矩阵函数见 [Matrix Functions](Matrix-Functions.md)。其余运算符在下面有更详细的说明。

表达式在矩阵语言中出现的一些场合下，可能会产生歧义：究竟是 “/” 作为运算符，还是作为子命令之间的分隔符。在这些场合下，只允许使用优先级高于 “/” 的运算符出现在括号之外。后续章节将这些称为 _受限表达式_。
