#### 7.7.10 统计分布函数

PSPP 可以计算若干标准统计分布的函数。这些函数根据函数类型与分布进行系统化命名。下表总体上描述了统计分布函数：

PDF.dist (x[, param…])
    

dist 的概率密度函数。x 的定义域取决于 dist。对于连续分布，结果为 x 处概率函数的密度，值域为非负实数；对于离散分布，结果为 x 的概率。

CDF.dist (x[, param…])
    

dist 的累积分布函数，即从该分布中抽取的随机变量小于 x 的概率。x 的定义域取决于 dist。结果为一个概率。

SIG.dist (x[, param…)
    

dist 的尾概率函数，即从该分布中抽取的随机变量大于 x 的概率。x 的定义域取决于 dist。结果为一个概率。仅有少数分布包含 `SIG` 函数。

IDF.dist (p[, param…])
    

dist 的逆分布函数，即使得 CDF 得出 p 的 x 值。p 的值为一个概率。值域取决于 dist，并与对应 CDF 的定义域相同。

RV.dist ([param…])
    

dist 的随机变量函数。值域取决于分布。

NPDF.dist (x[, param…])
    

非中心概率密度函数。结果为给定非中心分布在 x 处的密度。x 的定义域取决于 dist。值域为非负实数。仅有少数分布包含 `NPDF` 函数。

NCDF.dist (x[, param…])
    

dist 的非中心累积分布函数，即从给定非中心分布中抽取的随机变量小于 x 的概率。x 的定义域取决于 dist。结果为一个概率。仅有少数分布包含 NCDF 函数。
