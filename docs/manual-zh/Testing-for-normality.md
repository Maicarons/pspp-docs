#### 5.2.5 正态性检验

许多统计检验依赖于数据的某些特性。许多线性检验所依赖的一个常见特性是正态性——数据必须来自正态分布。因此，在选择要使用的检验方法之前，有必要确认正态性。其中一种方法是使用 `EXAMINE` 命令。

在下面的示例中，一位研究者正在检查某工程公司所生产设备的故障率。文件 repairs.sav 包含受研究的部分设备的平均故障间隔时间（**mtbf**）。在对数据进行线性分析之前，研究者想要确认数据是正态分布的。

    
    
    PSPP> get file='/usr/local/share/pspp/examples/repairs.sav'.
    PSPP> examine mtbf
                    /statistics=descriptives.
    

这将产生如下输出：

|  |  |  | 统计量 | 标准误 |
| --- | --- | --- | --- | --- |
| 平均故障间隔时间（月） | 均值 | 8.78 | 1.10 |  |
| 均值 95% 置信区间 | 下限 | 6.53 |  |  |
| 上限 | 11.04 |  |  |  |
| 5% 截尾均值 | 8.20 |  |  |  |
| 中位数 | 8.29 |  |  |  |
| 方差 | 36.34 |  |  |  |
| 标准差 | 6.03 |  |  |  |
| 最小值 | 1.63 |  |  |  |
| 最大值 | 26.47 |  |  |  |
| 全距 | 24.84 |  |  |  |
| 四分位距 | 6.03 |  |  |  |
| 偏度 | 1.65 | .43 |  |  |
| 峰度 | 3.41 | .83 |  |  |

正态分布的偏度与峰度均为零。上面输出中 **mtbf** 的偏度清楚地表明，mtbf 数值具有较大的正偏态，因此并非来自正态分布的变量。正偏态通常可以通过应用对数变换来补偿，如下面该示例的延续部分所示：

    
    
    PSPP> compute mtbf_ln = ln (mtbf).
    PSPP> examine mtbf_ln
                    /statistics=descriptives.
    

这将产生如下附加输出：

|  |  |  | 统计量 | 标准误 |
| --- | --- | --- | --- | --- |
| mtbf_ln | 均值 | 1.95 | .13 |  |
| 均值 95% 置信区间 | 下限 | 1.69 |  |  |
| 上限 | 2.22 |  |  |  |
| 5% 截尾均值 | 1.96 |  |  |  |
| 中位数 | 2.11 |  |  |  |
| 方差 | .49 |  |  |  |
| 标准差 | .70 |  |  |  |
| 最小值 | .49 |  |  |  |
| 最大值 | 3.28 |  |  |  |
| 全距 | 2.79 |  |  |  |
| 四分位距 | .88 |  |  |  |
| 偏度 | -.37 | .43 |  |  |
| 峰度 | .01 | .83 |  |  |

上面第一行的 `COMPUTE` 命令执行了对数变换：

    
    
    compute mtbf_ln = ln (mtbf).
    

这种用法并未重新定义已有变量，而是用 `COMPUTE` 定义了一个新变量 **mtbf_ln**，它是 **mtbf** 的自然对数。本示例的最后一条命令对这个新变量调用 `EXAMINE`。结果显示，**mtbf_ln** 的偏度与峰度都非常接近零。这在一定程度上表明 **mtbf_ln** 变量是正态分布的，因此可以安全地用于线性分析。如果找不到合适的变换，那么与其使用线性检验，不如考虑使用适当的非参数检验。关于非参数检验的信息，请见 [NPAR TESTS](NPAR-TESTS.md)。
