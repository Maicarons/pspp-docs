#### 6.7.5 暂用变量

大多数情况下，变量不会在个案之间保留其值。相反，要么它们正从数据文件或活动数据集中读取（此时它们取所读取的值），要么如果是用 `COMPUTE` 或其他转换创建的，则会根据类型初始化为系统缺失值或空格。

不过，有时拥有一个能在个案之间保留其值的变量会很有用。你可以用 `LEAVE`（参见 [LEAVE](LEAVE.md)）做到这一点，也可以使用*暂用变量*。暂用变量是名称以井号（‘#’）开头的变量。

暂用变量与用 `LEAVE` 保留的变量具有相同的属性：它们在个案之间保留其值，并且对第一个个案初始化为 0 或空格。它们还有一个额外属性，即在任何过程执行之前被删除。因此，暂用变量不能用于分析。若要在分析中使用暂用变量，请使用 `COMPUTE`（参见 [COMPUTE](COMPUTE.md)）将其值复制到一个普通变量，然后在该分析中使用那个普通变量。
