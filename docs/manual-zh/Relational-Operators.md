### 7.6 关系运算符

关系运算符接受数值或字符串操作数，并产生布尔结果。

字符串不能与数字比较。当比较长度不同的字符串时，较短的字符串会在右侧补空格，以匹配较长字符串的长度。

除相等或不相等测试外，字符串比较的结果取决于所使用的字符集。字符串比较区分大小写。


`a EQ b`
`a = b`

如果 a 等于 b 则为真。

`a LE b`
`a <= b`

如果 a 小于或等于 b 则为真。

`a LT b`
`a < b`

如果 a 小于 b 则为真。

`a GE b`
`a >= b`

如果 a 大于或等于 b 则为真。

`a GT b`
`a > b`

如果 a 大于 b 则为真。

`a NE b`
`a ~= b`
`a <> b`

如果 a 不等于 b 则为真。
