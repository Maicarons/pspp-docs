## 9 系统文件与可移植文件的输入/输出

本章中的命令用于读取、写入和检查系统文件与可移植文件。

| • APPLY DICTIONARY |  | 将系统文件字典应用到活动数据集。 |
| --- | --- | --- |
| • EXPORT |  | 写入可移植文件。 |
| • GET |  | 从系统文件读取。 |
| • GET DATA |  | 从外部文件读取。 |
| • IMPORT |  | 从可移植文件读取。 |
| • SAVE |  | 写入系统文件。 |
| • SAVE DATA COLLECTION |  | 写入系统文件与元数据文件。 |
| • SAVE TRANSLATE |  | 以外部文件格式写入数据。 |
| • SYSFILE INFO |  | 显示系统文件字典。 |
| • XEXPORT |  | 作为变换写入可移植文件。 |
| • XSAVE |  | 作为变换写入系统文件。 |
