#### 5.1.1 定义变量

变量有两种基本类型，_即_：_数值型_和_字符串型_。像年龄、身高和满意度这样的变量是数值型的，而 name 是字符串变量。字符串变量最好保留给辅助人工观察的说明性数据。不过，它们也可用于名义型或分类型数据。

以下示例定义了两个变量 **forename** 和 **height**，并通过手动输入将数据读入其中：

    PSPP> data list list /forename (A12) height.
    PSPP> begin data.
    data> Ahmed 188
    data> Bertram 167
    data> Catherine 134.231
    data> David 109.1
    data> end data
    PSPP>

关于此示例有几点需要注意。

  * ‘data list list’这两个词是 `DATA LIST` 命令的一个示例。参见 [DATA LIST](DATA-LIST.md)。它告诉 PSPP 准备读取数据。单词‘list’有意出现了两次。第一次出现是 `DATA LIST` 调用的一部分，而第二次告诉 PSPP 数据应作为每个记录一行的自由格式数据读取。
  * ‘/’字符很重要。它标志着您希望定义的变量列表的开始。
  * 文本‘forename’是第一个变量的名称，而‘(A12)’表示变量 **forename** 是一个字符串变量，其最大长度为 12 字节。第二个变量的名称由文本‘height’指定。由于没有给出格式，该变量使用默认格式。通常默认格式期望数值数据，应按操作系统的区域设置输入。因此，该示例对于英文区域设置以及使用句点（‘.’）作为小数分隔符的其他区域设置是正确的。但是，如果您使用的系统区域设置使用逗号（‘,’）作为小数分隔符，那么在后续各行中应将‘.’替换为‘,’。或者，您可以通过在单词‘height’之后附加文本‘DOT8.3’，显式告诉 PSPP 该 **height** 变量使用句点作为小数分隔符来读取。有关数据格式的更多信息，参见 [输入与输出格式](Input-and-Output-Formats.md)。
  * 通常，PSPP 在期望命令时显示提示符 PSPP>。但是，当它期望数据时，提示符变为 data>，以便您知道要输入数据而非命令。
  * 每个命令的末尾都有一个终止用的‘.’，它告诉 PSPP 已遇到命令的结束。在期望数据时（_即_ 当 data> 提示符当前有效时）不应输入‘.’，因为它只适用于终止命令。
