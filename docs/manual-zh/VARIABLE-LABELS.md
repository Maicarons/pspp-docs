### 11.7 VARIABLE LABELS

除了变量的名称之外，每个变量还可以有一个_标签_。变量名是变量的一个简明、易输入的助记符，而标签可以更长、更具描述性。

    
    
    VARIABLE LABELS
            variable ’label’
            [variable ’label’]…
    

`VARIABLE LABELS` 将解释性名称与变量相关联。这个名称称为_变量标签_ ，由统计过程显示。

将每个变量及其标签（带引号的字符串）一起指定。变量—标签对可以用可选的斜杠 ‘/’ 分隔。

如果所列变量已有标签，则新标签会替换它。将空字符串指定为标签，例如 ‘'''’，可移除标签。
