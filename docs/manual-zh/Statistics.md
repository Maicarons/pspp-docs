## 15 统计

本章记录 PSPP 目前支持的统计过程。

| • DESCRIPTIVES |  | 描述性统计。 |
| --- | --- | --- |
| • FREQUENCIES |  | 频数表。 |
| • EXAMINE |  | 检验数据正态性。 |
| • GRAPH |  | 绘制数据。 |
| • CORRELATIONS |  | 相关表。 |
| • CROSSTABS |  | 交叉表。 |
| • CTABLES |  | 自定义表格。 |
| • FACTOR |  | 因子分析与主成分分析。 |
| • GLM |  | 单变量线性模型。 |
| • LOGISTIC REGRESSION |  | 二元逻辑回归。 |
| • MEANS |  | 均值及其他统计量。 |
| • NPAR TESTS |  | 非参数检验。 |
| • T-TEST |  | 关于均值的假设检验。 |
| • ONEWAY |  | 单因素方差分析。 |
| • QUICK CLUSTER |  | K 均值聚类。 |
| • RANK |  | 计算秩得分。 |
| • REGRESSION |  | 线性回归。 |
| • RELIABILITY |  | 信度分析。 |
| • ROC |  | 受试者工作特征。 |
