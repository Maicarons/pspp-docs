## 8 数据输入与输出

数据是 PSPP 语言的核心。每个数据都属于一个_个案_（也称为_观测_）。每个个案代表一个个体或“实验单元”。例如，在一项调查结果中，受访者的姓名、性别、年龄等以及他们的回答都是数据，与单个受访者相关的数据就是一个个案。本章考察 PSPP 用于定义变量以及读写数据的命令。还有替代命令可用于从预定义来源（如系统文件或数据库）读取数据（参见 [GET DATA](GET.md)）。

> **注意：** 这些命令告诉 PSPP 如何读取数据，但数据在实际执行某个规程之前不会被真正读取。

| • BEGIN DATA |  | 在语法文件中嵌入数据。 |
| --- | --- | --- |
| • CLOSE FILE HANDLE |  | 关闭文件句柄。 |
| • DATAFILE ATTRIBUTE |  | 在数据文件上设置自定义属性。 |
| • DATASET |  | 管理多个数据集。 |
| • DATA LIST |  | 基础的数据读取命令。 |
| • END CASE |  | 输出当前个案。 |
| • END FILE |  | 终止当前的输入程序。 |
| • FILE HANDLE |  | 支持特殊文件格式。 |
| • INPUT PROGRAM |  | 支持复杂的输入程序。 |
| • LIST |  | 列出活动数据集中的个案。 |
| • NEW FILE |  | 清空活动数据集。 |
| • PRINT |  | 以打印格式显示值。 |
| • PRINT EJECT |  | 弹出当前页然后打印。 |
| • PRINT SPACE |  | 打印空行。 |
| • REREAD |  | 再次查看前一行输入。 |
| • WRITE |  | 以写入格式显示值。 |
