#### 7.7.1 Mathematical Functions

高级数学函数接受数值参数并产生数值结果。

Function: __**EXP** _( exponent)_

返回 _e_（约等于 2.71828）的 exponent 次幂。

Function: __**LG10** _( number)_

取 number 的以 10 为底的对数。如果 number 不是正数，则结果为系统缺失值。

Function: __**LN** _( number)_

取 number 的以 _e_ 为底的对数。如果 number 不是正数，则结果为系统缺失值。

Function: __**LNGAMMA** _( number)_

产生 number 的完整 gamma 函数的以 _e_ 为底的对数。如果 number 是负整数，则结果为系统缺失值。

Function: __**SQRT** _( number)_

取 number 的平方根。如果 number 为负数，则结果为系统缺失值。
