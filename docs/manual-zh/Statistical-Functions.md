#### 7.7.6 统计函数

统计函数用于计算一组值的描述性统计量。部分统计量可在数值或字符串值上计算；其余只能用于数值值。其结果与参数的类型相同。当前个案的加权因子（见 [WEIGHT](WEIGHT.md)）对统计函数没有影响。

这些函数的参数列表可以使用 `var1 TO var2` 语法包含整个变量范围。

与大多数函数不同，即使部分参数为缺失值，统计函数仍可返回非缺失值。默认情况下，大多数统计函数只需 1 个非缺失值即可返回非缺失结果，但 `CFVAR`、`SD` 和 `VARIANCE` 需要 2 个。可以通过在函数名后追加一个点号及有效参数的最小数量来提高（但不能降低）该默认值。例如，`MEAN.3(X, Y, Z)` 仅在 ‘X’、‘Y’、‘Z’ 全部有效时才返回非缺失值。

函数：__**CFVAR** _( number, number[, …])_
    

返回 number 各值的变异系数。（变异系数为标准差除以均值。）

函数：__**MAX** _( value, value[, …])_
    

返回最大值。这些值可以是数值或字符串。

函数：__**MEAN** _( number, number[, …])_
    

返回 number 各值的均值。

函数：__**MEDIAN** _( number, number[, …])_
    

返回 number 各值的中位数。若非缺失参数个数为偶数，则取中间两个值的均值。

函数：__**MIN** _( value, value[, …])_
    

返回最小值。这些值可以是数值或字符串。

函数：__**SD** _( number, number[, …])_
    

返回 number 各值的标准差。

函数：__**SUM** _( number, number[, …])_
    

返回 number 各值的和。

函数：__**VARIANCE** _( number, number[, …])_
    

返回 number 各值的方差。
