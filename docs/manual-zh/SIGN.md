#### 15.12.12 符号检验


         [ /SIGN var_list [ WITH var_list [ (PAIRED) ]]]


`/SIGN` 子命令检验所列变量中位数之间的差异。该检验不对数据的分布作任何假设。

如果省略 `WITH` 关键字，则对所列变量的所有组合执行检验。如果给出 `WITH` 关键字且同时给出 `(PAIRED)` 关键字，则 `WITH` 之前的变量个数必须与之后的变量个数相同。此时，对每一对相应变量执行检验。如果给出 `WITH` 关键字但省略 `(PAIRED)` 关键字，则对 `WITH` 之前每个变量与 `WITH` 之后每个变量的组合执行检验。
