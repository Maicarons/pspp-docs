#### 15.12.10 Median Test

         [ /MEDIAN [(value)] = var_list BY variable (value1, value2) ]

中位数检验用于检验独立样本是否来自具有共同中位数的总体。用于检验样本的总体中位数可以在 `/MEDIAN` 子命令之后的括号内给出。如果未给出，则从中位数从所有样本的并集中推算。

要检验的样本变量应紧接在‘=’号之后。`BY` 关键字必须随之出现，然后为分组变量。其后应跟括号内的两个值。如果第一个值大于第二个值，则使用这两个值确定分组，执行 2 样本检验。但是，如果第一个变量小于第二个变量，则执行 _k_ 样本检验，所用的组取值为所遇到的、位于区间 [value1,value2] 内的所有值。
