#### 15.7.9.1 单元格定义变量的缺失值

对于将表划分为单元格的变量，[CTABLES Per-Variable Category Options](CTABLES-Per_002dVariable-Category-Options.md) 中描述的各变量类别选项决定了哪些数据被分析。如果此类变量的任一类别会排除某个个案，则该个案不被纳入。

作为示例，考虑以下完全人为构造的数据集，其中 ‘x’ 和 ‘y’ 是缺失值为 9 的分类变量，‘z’ 是标度变量：

| x | y | z |
| --- | --- | --- |
| 1 | 1 | 1 |
| 1 | 2 | 10 |
| 1 | 9 | 100 |
| 2 | 1 | 1000 |
| 2 | 2 | 10000 |
| 2 | 9 | 100000 |
| 9 | 1 | 1000000 |
| 9 | 2 | 10000000 |
| 9 | 9 | 100000000 |

使用 ‘x’ 和 ‘y’ 定义单元格，并对 ‘z’ 进行汇总，默认情况下 PSPP 会省略所有 ‘x’ 或 ‘y’（或二者）缺失的个案：

    
    CTABLES /TABLE x > y > z [SUM].
    

|  |  |  |  |  | Sum |
| --- | --- | --- | --- | --- | --- |
| x | 1 | y | 1 | z | 1 |
| 2 | z | 10 |  |  |  |
| 2 | y | 1 | z | 1000 |  |
| 2 | z | 10000 |  |  |  |

然而，如果我们添加 `CATEGORIES` 说明以包含 ‘y’ 或 ‘x’ 和 ‘y’ 的缺失值，输出表就会包含它们，如下所示：

    
    CTABLES /TABLE x > y > z [SUM] /CATEGORIES VARIABLES=y MISSING=INCLUDE.
    CTABLES /TABLE x > y > z [SUM] /CATEGORIES VARIABLES=x y MISSING=INCLUDE.
    

|  |  |  |  |  | Sum |
| --- | --- | --- | --- | --- | --- |
| x | 1 | y | 1 | z | 1 |
| 2 | z | 10 |  |  |  |
| 9 | z | 100 |  |  |  |
| 2 | y | 1 | z | 1000 |  |
| 2 | z | 10000 |  |  |  |
| 9 | z | 100000 |  |  |  |
|  |  |  |  |  | Sum |
| x | 1 | y | 1 | z | 1 |
| 2 | z | 10 |  |  |  |
| 9 | z | 100 |  |  |  |
| 2 | y | 1 | z | 1000 |  |
| 2 | z | 10000 |  |  |  |
| 9 | z | 100000 |  |  |  |
| 9 | y | 1 | z | 1000000 |  |
| 2 | z | 10000000 |  |  |  |
| 9 | z | 100000000 |  |  |  |
