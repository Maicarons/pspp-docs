### 6.7 数据集

PSPP 处理组织为_数据集_的数据。一个数据集由一组_变量_组成，这些变量合在一起被称为构成一个_字典_，以及一个或多个_个案_，每个个案对每个变量各有一个值。

在任何时刻，PSPP 恰好有一个特殊的数据集，称为_活动数据集_。大多数 PSPP 命令只与活动数据集一起工作。除了活动数据集之外，PSPP 还支持任意数量的额外已打开数据集。`DATASET` 命令可以从已打开的数据集中选择一个新的活动数据集，以及创建和销毁数据集（参见 [DATASET](DATASET.md)）。

下面的各节更详细地描述变量。

| • 属性 |  | 变量的属性。 |
| --- | --- | --- |
| • 系统变量 |  | 由 PSPP 自动定义的变量。 |
| • 变量集合 |  | 变量名列表。 |
| • 输入与输出格式 |  | 输入与输出格式。 |
| • 暂用变量 |  | 由规程删除的变量。 |
