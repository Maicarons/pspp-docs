## 11 Manipulating Variables

数据集中的每个值都与一个_变量_相关联。变量描述这些值代表什么以及这些值的属性，例如它们应显示的格式、是数值型还是字母型，以及应如何表示缺失值。有几个实用命令用于检查和调整变量。

| • DISPLAY |  | 显示关于活动数据集的信息。 |
| --- | --- | --- |
| • NUMERIC |  | 创建新的数值变量。 |
| • STRING |  | 创建新的字符串变量。 |
| • RENAME VARIABLES |  | 重命名变量。 |
| • SORT VARIABLES |  | 重新排序变量。 |
| • DELETE VARIABLES |  | 删除变量。 |
| • VARIABLE LABELS |  | 为变量设置变量标签。 |
| • PRINT FORMATS |  | 设置变量打印格式。 |
| • WRITE FORMATS |  | 设置变量写入格式。 |
| • FORMATS |  | 设置打印和写入格式。 |
| • VALUE LABELS |  | 为变量设置值标签。 |
| • ADD VALUE LABELS |  | 为变量添加值标签。 |
| • MISSING VALUES |  | 为变量设置缺失值。 |
| • VARIABLE ATTRIBUTE |  | 在变量上设置自定义属性。 |
| • VARIABLE ALIGNMENT |  | 设置显示的对齐方式。 |
| • VARIABLE WIDTH |  | 设置显示宽度。 |
| • VARIABLE LEVEL |  | 设置测量级别。 |
| • VARIABLE ROLE |  | 设置变量在分析中所扮演的角色。 |
| • VECTOR |  | 声明一个变量数组。 |
| • MRSETS |  | 添加、修改和列出多重响应集。 |
| • LEAVE |  | 不在个案之间清除变量。 |
