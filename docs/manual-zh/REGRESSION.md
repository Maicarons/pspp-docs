### 15.17 REGRESSION

`REGRESSION` 过程通过最小二乘估计将线性模型拟合到数据上。该过程适用于满足线性回归典型假设的数据：

  * 数据集包含因变量的 _n_ 个观测，即 _Y_1,…,Y_n_ ，以及一个或多个解释变量的 _n_ 个观测。设 _X_{11}, X_{12}_ , …, _X_{1n}_ 表示第一个解释变量的 _n_ 个观测；_X_{21}_ ,…,_X_{2n}_ 表示第二个解释变量的 _n_ 个观测；_X_{k1}_ ,…,_X_{kn}_ 表示第 _k_ 个解释变量的 _n_ 个观测。
  * 因变量 _Y_ 与解释变量之间具有如下关系：_Y_i = b_0 + b_1 X_{1i} + ... + b_k X_{ki} + Z_i_ ，其中 _b_0, b_1, …, b_k_ 是未知系数，_Z_1,…,Z_n_ 是独立的、服从正态分布且均值为零、具有共同方差的*噪声*项。噪声（或称*误差*）项是未被观测到的。这种关系称为*线性模型*。

`REGRESSION` 过程估计系数 _b_0,…,b_k_ 并生成与线性模型推断相关的输出。
