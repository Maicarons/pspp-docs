### 19.6 输入选择选项

`dir` 和 `convert` 命令默认对源 SPV 文件中的所有对象进行操作，输出查看器窗口中不可见的对象除外。用户可以指定这些选项以选择输入对象的子集。当使用多个选项时，仅选择满足所有选项的对象：

\--select=[^]class…
    
仅包含给定类别的对象；带有前导 ‘^’ 时，仅包含不在该类别中的对象。使用逗号分隔多个类别。支持的类别有：

> `charts headings logs models tables texts trees warnings outlineheaders pagetitle notes unknown other`

使用 \--select=help 打印此类别列表。

\--commands=[^]command…
\--subtypes=[^]subtype…
\--labels=[^]label…
    
仅包含具有指定命令、子类型或标签的对象。带有前导 ‘^’ 时，仅包含不匹配的对象。可以指定多个值，以逗号分隔。值末尾的星号充当通配符。

\--command 选项匹配命令标识符，不区分大小写。由单个命令产生的所有对象使用相同、唯一的命令标识符。命令标识符始终为英文，不受输出语言影响。它们通常与 PSPP 语法中的命令名不同。使用 `pspp-output` 程序的 `dir` 命令可在特定输出中打印命令标识符。

\--subtypes 选项匹配命令中的特定表格，不区分大小写。子类型不一定唯一：产生类似输出表格的两个命令可能使用相同的子类型。子类型始终为英文，`dir` 会打印它们。

\--labels 选项匹配表格输出中的标签（即表格标题）。标签受输出语言、变量名和标签、拆分文件设置及其他因素影响。

\--nth-commands=n…
    
仅包含来自与 \--command 匹配的第 n 个命令的对象（如果未指定 \--command，则为第 n 个命令整体），其中 n 为 1 表示第一个命令，2 表示第二个，依此类推。

\--instances=instance…
    
包含在使用其他条件在单个命令中匹配的对象的指定实例。实例可以是数字（1 表示第一个实例，2 表示第二个，依此类推）或 `last` 表示最后一个实例。

\--show-hidden
    
在输出中包含隐藏的输出对象。默认情况下它们被排除。

\--or
    
分隔两组选择选项。任一组选项选择的对象都包含在输出中。

以下额外的输入选择选项主要供 PSPP 开发人员使用：

\--errors
    
仅包含读取时导致错误的对象。配合 `convert` 命令使用时，这与 \--force 选项结合最有用。

\--members=member…
    
仅包含包含所列 Zip 文件成员的对象。可以包含多个名称，以逗号分隔。SPV 文件中的成员可通过在 `dir` 命令中添加 \--show-members 选项列出，或使用许多操作系统附带的 `zipinfo` 程序列出。`pspp-output` 读取 SPV 文件时打印的错误消息通常也包含成员名称。

\--member-names
    
显示与每个对象自身正上方关联的 Zip 成员的名称。
