#### 5.3.1 均值差异检验

一种常见的统计检验涉及关于均值的假设。`T-TEST` 命令用于判断两个独立的子集是否具有相同的均值。

一位研究者怀疑人的身高与核心体温可能因其性别不同而存在差异。为进行研究，他基于先前遇到的 physiology.sav 数据提出了两个原假设：

  * 总体中男性与女性的平均身高相等。 
  * 总体中男性与女性的平均体温相等。 

出于研究目的，研究者决定使用 0.05 的 p 值。

除 T 检验外，`T-TEST` 命令还会执行方差齐性的 Levene 检验。若方差相等，则可使用功效更高的 T 检验形式。但如果假定方差相等并不稳妥，则需要另一种计算方式。PSPP 会同时执行两种计算。

对于 **height** 变量，输出显示 Levene 检验的显著性为 0.33，这意味着当方差相等时，Levene 检验产生此结果的概率为 33%。若显著性小于 0.05，则假定方差相等就不稳妥了。然而，由于该值高于 0.05，方差齐性假设是安全的，可以使用“假定方差相等”行（即功效更高的检验）。查看该行，**height** 的 t 检验双尾显著性小于 0.05，因此可以安全地拒绝原假设，并得出男性与女性平均身高不相等的结论。

对于 **temperature** 变量，Levene 检验的显著性为 0.58，因此同样可以使用方差相等行。方差相等行显示 **temperature** 的双尾显著性为 0.20。由于该值大于 0.05，我们必须拒绝原假设，并得出证据不足以表明男性与女性的体温存在差异的结论。

本分析的语法为：

    
    
    PSPP> get file='/usr/local/share/pspp/examples/physiology.sav'.
    PSPP> recode height (179 = SYSMIS).
    PSPP> t-test group=sex(0,1) /variables = height temperature.
