#### 15.13.2 独立样本模式

`GROUPS` 子命令调用独立样本模式或“组”模式。此模式用于检验两组数值是否具有相同的总体均值。在此模式下，您还必须使用 `/VARIABLES` 子命令来告诉 PSPP 您要检验的因变量。

`GROUPS` 子命令中给出的变量是决定样本所属组的自变量。括号中的值是每个组的自变量特定值。如果省略括号且未给出值，则假定默认值为 1.0 和 2.0。

如果自变量是数值型的，则可以在括号内只指定一个值。如果这样做，自变量大于或等于此值的个案属于第一组，小于此值的个案属于第二组。使用这种形式的 `GROUPS` 子命令时，无论是否指定了 `/MISSING=LISTWISE`，自变量中的缺失值都按列表方式排除。

#### 15.13.2.1 示例 - 独立样本 T 检验

研究人员想知道在总体中，成年男性是否比成年女性高。样本从所研究的总体中抽取，并记录在文件 physiology.sav 中。

如前所述（见 [识别不正确的数据](Identifying-incorrect-data.md)），数据集中有一个样本包含明显不正确的身高值。因此使用 `SELECT` 命令将其排除在分析之外。

```
get file='physiology.sav'.  select if (height >= 200).  t-test /variables = height        /groups = sex(0,1).
```
