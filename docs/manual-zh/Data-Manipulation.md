## 12 数据变换

本章考察的 PSPP 规程会操纵数据，并为后续分析准备活动数据集。作为一般规则，它们不产生输出。

| • AGGREGATE |  | 将多个个案汇总为单个个案。 |
| --- | --- | --- |
| • AUTORECODE |  | 变量的自动重编码。 |
| • COMPUTE |  | 为变量赋一个计算所得的值。 |
| • COUNT |  | 对具有特定值的变量计数。 |
| • FLIP |  | 交换变量与个案。 |
| • IF |  | 条件性地赋一个计算所得的值。 |
| • RECODE |  | 将值从一组映射到另一组。 |
| • SORT CASES |  | 对活动数据集排序。 |
