#### 15.12.9 McNemar Test

         [ /MCNEMAR var_list [ WITH var_list [ (PAIRED) ]]]

使用 McNemar 检验来分析成对相关比例之间差异的显著性。

如果省略 `WITH` 关键字，则对所列变量的所有组合执行检验。如果给出了 `WITH` 关键字，并且也给出了 `(PAIRED)` 关键字，则 `WITH` 前面的变量个数必须与后面的变量个数相同。在这种情况下，对每个相应变量对执行检验。如果给出了 `WITH` 关键字但省略了 `(PAIRED)` 关键字，则对 `WITH` 前面的每个变量与 `WITH` 后面的变量之间的每个组合执行检验。

每个变量中的数据必须是二分的。如果存在两个以上不同的变量，将发生错误并且检验不会运行。
