### 3.8 逗号分隔值（CSV）输出选项

要以逗号分隔值（CSV）格式生成输出，请在 PSPP 命令行上指定 -o 文件，并可选择性地后接下表中所示的任何选项，以自定义输出格式。

-O format=csv

指定输出格式。仅当 -o 上给出的文件名不以 .csv 结尾时才需要。

-O separator=字段分隔符

设置用于分隔字段的字符。默认值：逗号（‘,’）。

-O quote=限定符

将限定符设置为用于引用包含空白、分隔符（若分隔符包含多个字符，则为其中任意字符）或引用字符本身的字段的字符。如果限定符长于一个字符，则仅使用第一个字符；如果限定符为空字符串，则字段永远不会被引用。

-O titles=布尔值

是否打印表标题（简要说明）。默认值：`on`。

-O captions=布尔值

是否打印表说明文字（更详尽的描述）。默认值：on。

所使用的 CSV 格式是对 RFC 4180 所规定格式的扩展：

表

每一表行输出在单独一行上，每一列作为一个字段输出。跨多行或多列的单元格内容仅针对其左上角的行和列输出；其余部分作为空字段输出。

标题

当表具有标题且标题功能启用时，标题输出在表正上方，作为以‘Table:’为前缀的单个字段。

说明文字

当表具有说明文字且说明文字功能启用时，说明文字输出在表正下方，作为以‘Caption:’为前缀的单个字段。

脚注

在表内，脚注标记作为括号字母输出在单元格内容之后，_例如_‘[a]’、‘[b]’……。脚注本身在表主体之后输出，作为一个以‘Footnotes:’行开头、单独的两列表格。表中的每一行表示一个脚注：第一列是标记，第二列是文本。

文本

输出中的文本作为单独一行的字段打印。TITLE 和 SUBTITLE 产生类似的输出，分别以前缀‘Title:’或‘Subtitle:’开头。

消息

错误、警告和说明以与文本相同的方式打印。

图表

图表不包含在 CSV 输出中。

连续的输出项之间以空行分隔。
