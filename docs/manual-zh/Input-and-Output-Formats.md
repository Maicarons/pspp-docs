#### 6.7.4 输入与输出格式

_输入格式_ 描述如何将输入字段的内容解释为数字或字符串。它可以指定字段包含普通十进制数字、时间或日期、二进制或十六进制表示的数字，或其他几种表示法之一。输入格式由 `DATA LIST` 等将数据或语法文件读入 PSPP 活动数据集的命令使用。

每个输入格式都对应一个默认的 _输出格式_，指定稍后输出该值时使用的格式。始终可以显式指定类似于输入格式的输出格式。通常这是默认设置，但在输入格式不利于人类阅读的情况下，例如二进制或十六进制格式，默认输出格式是更易于阅读的十进制格式。

每个变量有两个输出格式，称为其 _打印格式_ 和 _写入格式_。打印格式用于大多数输出上下文；写入格式仅由 `WRITE` 使用（见 [WRITE](WRITE.md)）。新创建的变量具有相同的打印格式和写入格式，而最常用的更改格式命令 `FORMATS`（见 [FORMATS](FORMATS.md)）也会将两者都设置为相同的值。因此，大多数情况下，打印格式和写入格式之间的区别并不重要。

输入和输出格式以 `TYPEw` 或 `TYPEw.d` 形式的 _格式规范_ 提供给 PSPP，其中 TYPE 是后面描述的格式类型之一，w 是以列为单位的字段宽度，d 是可选的小数位数。如果省略 d，则假定为 0。某些格式不允许指定非零的 d。
