## 17 实用命令

无法归入其他任何类别的命令放在此处。

这些命令大多不受 `IF` 和 `LOOP` 等命令的影响：它们在输入中被遇到时只生效一次，无条件地生效。

| • ADD DOCUMENT |  | 向活动数据集添加说明性文本。 |
| --- | --- | --- |
| • CACHE |  | 为兼容性而保留（忽略）。 |
| • CD |  | 更改当前目录。 |
| • COMMENT |  | 为你的语法文件添加说明。 |
| • DOCUMENT |  | 为活动数据集添加说明。 |
| • DISPLAY DOCUMENTS |  | 显示活动数据集的文档。 |
| • DISPLAY FILE LABEL |  | 显示活动数据集的标签。 |
| • DROP DOCUMENTS |  | 从活动数据集中移除文档。 |
| • ECHO |  | 向输出流写入一个字符串。 |
| • ERASE |  | 删除一个文件。 |
| • EXECUTE |  | 执行待定的变换。 |
| • FILE LABEL |  | 设置活动数据集的标签。 |
| • FINISH |  | 终止 PSPP 会话。 |
| • HOST |  | 临时返回操作系统。 |
| • INCLUDE |  | 在当前文件中包含一个文件。 |
| • INSERT |  | 在当前文件中插入一个文件。 |
| • OUTPUT |  | 修改输出的外观。 |
| • PERMISSIONS |  | 更改文件的权限。 |
| • PRESERVE and RESTORE |  | 保存设置并在以后恢复。 |
| • SET |  | 调整 PSPP 运行时参数。 |
| • SHOW |  | 显示运行时参数。 |
| • SUBTITLE |  | 提供文档副标题。 |
| • TITLE |  | 提供文档标题。 |
