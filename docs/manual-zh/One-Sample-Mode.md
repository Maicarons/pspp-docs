#### 15.13.1 单样本模式

`TESTVAL` 子命令启用单样本模式。该模式用于将总体均值与假设均值进行检验。赋予 `TESTVAL` 子命令的值即为你想检验的对照值。在此模式下，你还必须使用 `/VARIABLES` 子命令告诉 PSPP 你想检验哪些变量。

#### 15.13.1.1 示例 — 单样本 T 检验

一位研究人员想知道某总体中人群的体重是否与全国平均值不同。样本从该总体中抽取，并记录在文件 physiology.sav 中。根据卫生部门的数据，她得知健康成年人的全国平均体重为 76.8kg。因此 `TESTVAL` 设为 76.8。于是原假设为：所抽取样本来源的总体的平均体重为 76.8kg。

如前所述（参见 [Identifying incorrect data](Identifying-incorrect-data.md)），数据集中有一个样本的体重值明显不正确。因此使用 `SELECT` 命令将其从分析中排除。

```
get file='physiology.sav'.  select if (weight > 0).  t-test testval = 76.8 	/variables = weight.
```
