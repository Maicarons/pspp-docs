#### 16.4.1.5 Elementwise Binary Operators

逐元素二元运算符要求它们的操作数是具有相同维度的矩阵。或者，如果一个操作数是标量，则其值被视为被复制到其他操作数的维度。结果是一个与操作数大小相同的矩阵，其中每个元素是运算符作用于操作数对应元素的结果。

逐元素二元运算符列出如下。

  * 算术运算符，用于常见的算术运算：

`+`

加法。

`-`

减法。

`*`

乘法，如果一个操作数是标量。（否则这是矩阵乘法，如下所述。）

`/` 或 `&/`

除法。

`&*`

乘法。

`&**`

乘方。

  * 关系运算符，比较为真时结果为 1，为假时结果为 0：

`<` 或 `LT`

小于。

`<=` 或 `LE`

小于或等于。

`=` 或 `EQ`

等于。

`>` 或 `GT`

大于。

`>=` 或 `GE`

大于或等于。

`<>` 或 `~=` 或 `NE`

不等于。

  * 逻辑运算符，将正操作数视为真，非正操作数视为假。假时产生 0，真时产生 1：

`AND`

如果两个操作数都为真则为真。

`OR`

如果至少一个操作数为真则为真。

`XOR`

如果恰好一个操作数为真则为真。

示例：

| 1 + 2 | ⇒ | 3 |
| --- | --- | --- |
| 1 + {3; 4} | ⇒ | {4; 5} |
| {66, 77; 88, 99} + 5 | ⇒ | {71, 82; 93, 104} |
| {4, 8; 3, 7} + {1, 0; 5, 2} | ⇒ | {5, 8; 8, 9} |
| {1, 2; 3, 4} < {4, 3; 2, 1} | ⇒ | {1, 1; 0, 0} |
| {1, 3; 2, 4} >= 3 | ⇒ | {0, 1; 0, 1} |
| {0, 0; 1, 1} AND {0, 1; 0, 1} | ⇒ | {0, 0; 0, 1} |
