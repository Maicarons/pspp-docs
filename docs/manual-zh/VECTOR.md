### 11.19 VECTOR
    
    
    Two possible syntaxes:
            VECTOR vec_name=var_list.
            VECTOR vec_name_list(count [format]).
    

`VECTOR` 允许将一组变量当作一个数组的连续成员来访问，使用 vector(index) 记法。

要用一组已有变量构成向量，请指定向量名，后跟等号（‘=’）以及要放入向量的变量。这些变量必须全部为数值型或全部为字符串型，且字符串变量必须具有相同的宽度。

要同时构成一个向量并创建变量，请指定一个或多个向量名，后跟括号中的计数。这将创建名为 `vec1` 至 `veccount` 的变量。默认情况下，新变量为数值型，格式为 F8.2，但可以在括号内计数之前或之后指定另一种格式，并以空白或逗号与其分隔。使用诸如 A8 的字符串格式时，变量将为字符串变量；使用数值格式时，变量将为数值型。包含后缀的变量名长度不得超过 64 个字符，且这些变量在 `VECTOR` 之前均不能已存在。

用 `VECTOR` 创建的向量在任何过程或类过程命令执行后消失。向量中包含的变量会保留，除非它们是临时变量（见 [临时变量](Scratch-Variables.md)）。

向量中的变量可在表达式中使用 `vector(index)` 语法引用。
