#### 16.4.2.1 Elementwise Functions

这些函数独立地作用于其参数的每个元素，就像逐元素运算符一样（参见 [Matrix Elementwise Binary Operators](Matrix-Elementwise-Binary-Operators.md)）。

Matrix Function: **ABS** _( M)_

取 M 每个元素的绝对值。

`ABS({-1, 2; -3, 0}) ⇒ {1, 2; 3, 0}`

Matrix Function: **ARSIN** _( M)_
Matrix Function: **ARTAN** _( M)_

分别计算 M 中每个元素的反正弦或反正切。结果以弧度表示，介于 _-\pi/2_ 和 _+\pi/2_ 之间（含）。

_\pi_ 的值可以计算为 `4*ARTAN(1)`。

`ARSIN({-1, 0, 1}) ⇒ {-1.57, 0, 1.57}`（约等于）

`ARTAN({-5, -1, 1, 5}) ⇒ {-1.37, -.79, .79, 1.37}`（约等于）

Matrix Function: **COS** _( M)_
Matrix Function: **SIN** _( M)_

分别计算 M 中每个元素的余弦或正弦，元素必须以弧度表示。

`COS({0.785, 1.57; 3.14, 1.57 + 3.14}) ⇒ {.71, 0; -1, 0}`（约等于）

Matrix Function: **EXP** _( M)_

计算 M 中每个元素 x 的 _e^x_。

`EXP({2, 3; 4, 5}) ⇒ {7.39, 20.09; 54.6, 148.4}`（约等于）

Matrix Function: **LG10** _( M)_
Matrix Function: **LN** _( M)_

分别计算 M 中每个元素以 10 为底或以 _e_ 为底的对数。

`LG10({1, 10, 100, 1000}) ⇒ {0, 1, 2, 3}`
`LG10(0) ⇒`（错误）

`LN({EXP(1), 1, 2, 3, 4}) ⇒ {1, 0, .69, 1.1, 1.39}`（约等于）
`LN(0) ⇒`（错误）

Matrix Function: **MOD** _( M, s)_

取 M 中每个元素对非零标量值 s 的模，即除以 s 的余数。结果的符号与 dividend（被除数）的符号相同。

`MOD({5, 4, 3, 2, 1, 0}, 3) ⇒ {2, 1, 0, 2, 1, 0}`
`MOD({5, 4, 3, 2, 1, 0}, -3) ⇒ {2, 1, 0, 2, 1, 0}`
`MOD({-5, -4, -3, -2, -1, 0}, 3) ⇒ {-2, -1, 0, -2, -1, 0}`
`MOD({-5, -4, -3, -2, -1, 0}, -3) ⇒ {-2, -1, 0, -2, -1, 0}`
`MOD({5, 4, 3, 2, 1, 0}, 1.5) ⇒ {.5, 1.0, .0, .5, 1.0, .0}`
`MOD({5, 4, 3, 2, 1, 0}, 0) ⇒`（错误）

Matrix Function: **RND** _( M)_
Matrix Function: **TRUNC** _( M)_

将 M 的每个元素舍入为整数。`RND` 舍入到最接近的整数，其中 .5 舍入到偶数整数；`TRUNC` 向零方向舍入。

`RND({-1.6, -1.5, -1.4}) ⇒ {-2, -2, -1}`
`RND({-.6, -.5, -.4}) ⇒ {-1, 0, 0}`
`RND({.4, .5, .6} ⇒ {0, 0, 1}`
`RND({1.4, 1.5, 1.6}) ⇒ {1, 2, 2}`

`TRUNC({-1.6, -1.5, -1.4}) ⇒ {-1, -1, -1}`
`TRUNC({-.6, -.5, -.4}) ⇒ {0, 0, 0}`
`TRUNC({.4, .5, .6} ⇒ {0, 0, 0}`
`TRUNC({1.4, 1.5, 1.6}) ⇒ {1, 1, 1}`

Matrix Function: **SQRT** _( M)_

取 M 每个元素的平方根，元素必须非负。

`SQRT({0, 1, 2, 4, 9, 81}) ⇒ {0, 1, 1.41, 2, 3, 9}`（约等于）
`SQRT(-1) ⇒`（错误）
