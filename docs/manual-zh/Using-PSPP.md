## 5 使用 PSPP

PSPP 是一款用于对抽样数据进行统计分析的工具。你可以用它发现数据中的模式，用一个数据子集来解释另一个数据子集的差异，并查明关于数据的某些看法是否成立。本章不试图介绍统计分析背后的理论，但会展示如何使用 PSPP 进行此类分析。

在本教程中，假设你在命令行下以其交互模式使用 PSPP。不过，示例命令也可以键入到一个文件中，并通过在 shell 提示符下键入 ‘pspp file-name’ 以事后模式执行，其中 file-name 是包含命令的文件名。或者，在图形界面中，你可以选择 文件 → 新建 → 语法 打开一个新的语法窗口，并在一段语法准备好执行时使用 运行 菜单。无论采用哪种方法，语法都是相同的。

使用交互方式时，PSPP 会用类似 PSPP> 或 data> 的字符串告诉你它正在等待你的数据。在本章的示例中，凡是看到类似这样的文本，都表示 PSPP 显示的提示符，_而非_ 你应该键入的内容。

本章通篇引用了若干示例数据文件。为了让你自己尝试这些示例，你应该已经随 PSPP 副本一起收到了这些文件。1

> **请注意：** 通常这些文件安装在目录 /usr/local/share/pspp/examples 中。但是，如果你的系统管理员或操作系统供应商选择将其安装到其他位置，你将不得不相应地调整示例。
