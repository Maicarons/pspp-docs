#### 15.12.13 Wilcoxon 配对符号秩检验
    
    
         [ /WILCOXON var_list [ WITH var_list [ (PAIRED) ]]]
    

`/WILCOXON` 子命令检验所列变量中位数之间的差异。该检验不对样本的方差做任何假设。但它确实假设分布是对称的。

如果省略 `WITH` 关键字，则对所列变量的所有组合执行检验。如果给出了 `WITH` 关键字，且也给出了 `(PAIRED)` 关键字，则 `WITH` 之前的变量个数必须与 `WITH` 之后的变量个数相同。此时，对每个相应的变量对执行检验。如果给出了 `WITH` 关键字但省略了 `(PAIRED)` 关键字，则对 `WITH` 之前的每个变量与 `WITH` 之后的变量之间的每个组合执行检验。
