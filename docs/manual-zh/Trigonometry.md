#### 7.7.3 三角函数

三角函数接受数值参数并产出数值结果。

函数：__**ARCOS** _( number)_
函数：__**ACOS** _( number)_
    

取 number 的反余弦（弧度）。若 number 不在 -1 到 1（含）之间，结果为系统缺失值。此函数为 PSPP 扩展。

函数：__**ARSIN** _( number)_
函数：__**ASIN** _( number)_
    

取 number 的反正弦（弧度）。若 number 不在 -1 到 1（含）之间，结果为系统缺失值。

函数：__**ARTAN** _( number)_
函数：__**ATAN** _( number)_
    

取 number 的反正切（弧度）。

函数：__**COS** _( angle)_
    

取 angle（应为弧度）的余弦。

函数：__**SIN** _( angle)_
    

取 angle（应为弧度）的正弦。

函数：__**TAN** _( angle)_
    

取 angle（应为弧度）的正切。对于过于接近 _π/2_ 奇数倍的 angle 值，结果为系统缺失值。可移植性：无。
