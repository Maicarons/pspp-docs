#### 5.2.4 检验数据一致性

对调查数据做的一项合理检查是计算信度。这能让统计人员有一定把握，确信问卷是被认真填写的。如果查看变量 **v1** 、**v3** 和 **v4** 的标签，你会注意到它们提出的问题非常相似。因此，人们会预期这些变量的值（在重新编码之后）彼此高度相关，我们可以用 `RELIABILITY` 命令（见 [RELIABILITY](RELIABILITY.md)）来检验这一点。下面的示例展示了一个 PSPP 会话，用户先对负向计分的变量进行重新编码，然后请求针对 **v1** 、**v3** 和 **v4** 的信度统计量。

    
    
    PSPP> get file='/usr/local/share/pspp/examples/hotel.sav'.
    PSPP> compute v3 = 6 - v3.
    PSPP> compute v5 = 6 - v5.
    PSPP> reliability v1, v3, v4.
    

这将产生如下输出：

| 个案数 | N | 百分比 |
| --- | --- | --- |
| 有效 | 17 | 100.0% |
| 排除 | 0 | .0% |
| 合计 | 17 | 100.0% |
| Cronbach's Alpha | 项目数 |  |
| .81 | 3 |  |

作为一个经验法则，许多统计人员认为 Cronbach's Alpha 值达到 0.7 或更高即表示数据可靠。

此处该值为 0.81，表明变量 **v1** 、**v3** 和 **v4** 之间具有较高程度的信度，因此我们执行的数据及重新编码得到了验证。
