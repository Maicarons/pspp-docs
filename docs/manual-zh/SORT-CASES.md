### 12.8 SORT CASES


    SORT CASES BY var_list[({D|A}] [ var_list[({D|A}] ] ...


`SORT CASES` 按一个或多个变量的值对活动数据集排序。

指定 `BY` 和要排序的变量列表。默认情况下，变量按升序排序。要覆盖排序顺序，可在变量列表之后指定 `(D)` 或 `(DOWN)` 得到降序，或指定 `(A)` 或 `(UP)` 得到升序。这些顺序对前面所列的所有变量生效，直到出现前一个 `(A)`、`(D)`、`(UP)` 或 `(DOWN)`。

`SORT CASES` 使用的排序算法是稳定的。这意味着排序变量取值相同的记录，在排序前后保持相同的相对顺序。因此，对已排序的文件重新排序不会影响个案的顺序。

`SORT CASES` 是一个过程。它会导致数据被读取。

`SORT CASES` 尝试在内存中对整个活动数据集排序。如果工作区耗尽，它会回退到一种归并排序算法，该算法会创建大量临时文件。

`SORT CASES` 不能出现在 `TEMPORARY` 之后。

#### 12.8.1 排序示例

在示例 12.6 中，文件 physiology.sav 的数据按两个变量排序，即 **sex** 降序、**temperature** 升序。

```
get file='physiology.sav'. sort cases by sex (D) temperature(A). list.
```
