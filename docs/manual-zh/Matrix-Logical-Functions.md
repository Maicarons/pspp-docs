#### 16.4.2.2 逻辑函数

Matrix Function: **ALL** _( M)_

如果 M 中所有元素都非零，则返回值为 1 的标量；如果至少有一个元素为零，则返回 0。

`ALL({1, 2, 3} < {2, 3, 4}) ⇒ 1`
`ALL({2, 2, 3} < {2, 3, 4}) ⇒ 0`
`ALL({2, 3, 3} < {2, 3, 4}) ⇒ 0`
`ALL({2, 3, 4} < {2, 3, 4}) ⇒ 0`

Matrix Function: **ANY** _( M)_

如果 M 中任一元素非零，则返回值为 1 的标量；如果所有元素都为零，则返回 0。

`ANY({1, 2, 3} < {2, 3, 4}) ⇒ 1`
`ANY({2, 2, 3} < {2, 3, 4}) ⇒ 1`
`ANY({2, 3, 3} < {2, 3, 4}) ⇒ 1`
`ANY({2, 3, 4} < {2, 3, 4}) ⇒ 0`
