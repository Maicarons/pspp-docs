#### 15.12.2 卡方检验
    
    
         [ /CHISQUARE=var_list[(lo,hi)] [/EXPECTED={EQUAL|f1, f2 … fn}] ]
    

`/CHISQUARE` 子命令对变量各分类的期望频数与观测频数之间的差异生成卡方统计量。可选地，变量列表后可出现一个取值范围。如果给定了范围，则非整数值会被截断，超出指定范围的值会被排除在分析之外。

`/EXPECTED` 子命令指定每个类别的期望取值。对于每个观测类别，必须恰好有一个非零期望值，否则必须指定 `EQUAL` 关键字。你可以使用记法 `n*f` 来指定 n 个连续的期望类别，它们都取频率 f。给定的频率是比例，而非绝对频率。频率之和不必为 1。如果未给出 `/EXPECTED` 子命令，则期望各频率相等。
