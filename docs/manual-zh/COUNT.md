### 12.4 COUNT
    
    
    COUNT var_name = var… (value…)
        [/var_name = var… (value…)]…
    
    Each value takes one of the following forms:
            number
            string
            num1 THRU num2
            MISSING
            SYSMIS
    where num1 is a numeric expression or the words LO  or LOWEST
          and num2 is a numeric expression  or HI or HIGHEST.
    

`COUNT` 创建或替换一个数值 _target_（目标）变量，用于统计每个个案在一个或多个 _test_（检验）变量中某个 _criterion_（判定）值或一组判定的出现次数。

目标变量的值始终为非负整数。它们永远不会缺失。目标变量被赋予 F8.2 输出格式。参见 [Input and Output Formats](Input-and-Output-Formats.md)。任何变量，包括字符串变量，都可以作为检验变量。

检验变量的用户缺失值与其他任何值一视同仁。它们**不会**被当作系统缺失值。作为判定值或落在判定值范围内的用户缺失值，会像其他值一样被计数。不过（对于数值变量），关键字 `MISSING` 可用于指代所有系统缺失值和用户缺失值。

`COUNT` 目标变量按指定顺序赋值。在命令 `COUNT A=A B(1) /B=A B(2).` 中，发生以下动作：

  * 统计 A 与 B 之间 1 出现的次数。
  * A 被赋为该值。
  * 统计 B 与 A 的**新**值之间 1 出现的次数。
  * B 被赋为该值。

尽管如此，所有 `COUNT` 判定变量必须在过程执行之前就已存在——它们不能是该命令前面作为目标变量创建的！请将此类命令拆分为两个独立的命令。
