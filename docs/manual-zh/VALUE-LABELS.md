### 11.11 VALUE LABELS

变量的值可以与任意文本字符串相关联。这样，一个短值可以代表一个更长、更具描述性的标签。

数值变量和字符串变量都可以给定标签。对于字符串变量，值区分大小写，因此例如，如果一个大写值及其小写变体都出现在数据中，则必须分别对其加标签。

    
    
    VALUE LABELS
            /var_list value ’label’ [value ’label’]…
    

`VALUE LABELS` 允许将变量的值与标签相关联。

要为一个或多个变量设置值标签，请在斜杠（‘/’）后指定变量名，后跟以空格分隔的值及其关联标签列表。

输出中的值标签通常会自动换行。在标签字符串中放入 ‘\n’ 可在该处强制换行。标签仍可能在其他位置被换行。

在执行 `VALUE LABELS` 之前，会清除所指定变量上任何已有的值标签。使用 `ADD VALUE LABELS`（见 [ADD VALUE LABELS](ADD-VALUE-LABELS.md)）可以在不清空已有标签的情况下添加值标签。
