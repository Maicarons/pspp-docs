#### 16.4.3 The `COMPUTE` Command
    
    
    COMPUTE _variable_[(_index_[,_index_])]=_expression_.
    

The `COMPUTE` command evaluates an expression and assigns the result to a variable or a submatrix of a variable. Assigning to a submatrix uses the same syntax as the index operator (see [Matrix Index Operator](Matrix-Index-Operator.md)).
