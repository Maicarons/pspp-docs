# 前言

## 编写说明

GNU PSPP 是一套自由软件，定位为 SPSS 统计产品语法与部分功能的开源替代。本书以 PSPP 2.0.1 版本为基础撰写，所有命令、语法与界面描述均锚定该版本的官方手册与真实软件行为，力求与后续各章口径保持一致。

写作的初衷，源于统计初学者在接触 PSPP 时常常面对两份落差：一份是零散、以英文术语为主的官方文档，另一份是论坛里真假难辨的操作经验。本书试图在二者之间搭一座桥——用中文把最常用的分析流程讲清楚，同时把"手册里写明了什么"与"界面上能推断什么"分开标注，避免读者把通用统计软件的界面习惯误当成 PSPP 的确定能力。

内容组织遵循由数据到结论的递进：先建立变量与数据集的概念，再依次展开描述统计、假设检验、方差分析与回归，最后落到图表呈现。每一章都配备可在 PSPP 中直接运行的示例，使读者在动手过程中建立判断，而非停留在概念层面。

## 读者对象

本书面向统计学初学者，以及第一次接触 PSPP 或 SPSS 类软件的研究者。无论你来自社会学、医学、教育学还是市场研究，只要工作中需要把问卷、实验记录或观测数据转化为可靠的定量结论，都能从中获益。

我们假定读者具备基础的统计常识，例如知道均值与标准差各自描述什么，但不需要事先掌握任何命令行工具。图形界面下的每一步操作都会给出对应的语法，便于日后把分析迁移到批处理脚本，也方便在服务器等无界面环境中复用。

## 本书特点

由浅入深。前几章只依赖最少的统计背景，随篇幅推进逐步引入检验与模型，使不同起点的读者都能跟上节奏。

以真实软件行为为准。书中的命令均经过 PSPP 2.0.1 实测或出自官方手册，不照搬其他软件的过期经验，也不渲染未经证实的功能。

示例驱动。每个核心过程都配有数据构想、操作步骤与结果解读，而非孤立地罗列语法，读者可边读边练。

区分两种知识来源。凡手册明确记载的菜单与对话框，标以【手册明示】；凡依据 PSPPIRE 或 SPSS 通用界面结构推断、手册未逐项文档化的，标以【界面推断】，并说明其性质，提醒读者以实际软件为准。

如实说明功能边界。PSPP 并非 SPSS 的完整克隆，部分过程尚未实现，本书会在相应位置明确指出，而非含糊带过，帮助读者在遇到限制时及时转向可行路径。

## 章节安排

全书共八章，另设一个附录。第一章介绍 PSPP 的定位、两种运行界面与开源许可，帮助读者建立整体认知；第二章讲解安装、启动与基础配置，并提示区域设置对数据录入的影响；第三章进入数据管理，覆盖变量定义、数据录入、从 Excel 与 CSV 导入、排序、拆分、筛选，以及变量的计算与重编码；第四章至第五章是统计核心，分别处理描述性统计与假设检验，含 t 检验与非参数方法；第六章讨论方差分析，单因素走 `ONEWAY`，双因素及以上须改用 `GLM`；第七章介绍相关与回归分析；第八章聚焦图表，说明散点图、直方图、条形图与箱线图的实现方式及其限制。附录提供命令到菜单路径的速查映射，方便在语法与界面之间对照查阅。

各章内容一览：

- 第一章　PSPP 概述
- 第二章　安装与配置
- 第三章　数据管理
- 第四章　描述性统计
- 第五章　假设检验
- 第六章　方差分析
- 第七章　回归分析
- 第八章　图表
- 附录　命令—菜单速查映射

## 符号与约定

PSPP 命令、子命令、变量名、文件扩展名及英文菜单项均保持英文原样，例如 `COMPUTE`、`/VARIABLES`、`psppire`、`.sav`，其后的中文为说明文字。

代码块内的语法为可在 PSPP 中运行的语句，以英文句点结尾；在 `data>` 提示符下交互录入时，不要再重复输入这个句点。

凡标注【界面推断】者，表示该项依据通用图形界面知识给出，PSPP 手册未逐项文档化，使用时请以实际软件中的表现为准。

统计符号采用通行约定：显著性水平记为 α，概率值记为 p，样本均值记为 x̄，样本标准差记为 s。其余统计量在正文中首次出现时一并给出说明，避免读者来回翻查。
