# 附录

## 附录 A · PSPP 命令速查表

下表在提纲"命令 → 菜单路径速查映射"基础上扩展为三列：命令、语法功能、关键子命令或注意点。其中【手册明示】表示手册中确实出现过的菜单/对话框引用；【界面推断】表示按 PSPP/SPSS 通用界面结构推断，其依据为通用界面知识，手册未逐项文档化，实际菜单名称可能随版本略有差异。PSPP 命令统一以英文句点 `.` 结尾（`data>` 提示符期间不要输入句点）。下表覆盖本书正文涉及的主要命令，未穷尽全部子命令；正文中已逐项展开的语法模板可与此表对照查阅。

| PSPP 命令 | 语法功能 | 关键子命令或注意点 |
|---|---|---|
| `pspp` / `psppire` | 启动命令行 / 图形界面 | 【推断】经终端或开始菜单启动；`pspp` 为文本界面，`psppire` 为图形界面 |
| `DATA LIST` + `BEGIN DATA` | 定义变量并录入数据 | 【推断】对应 Variable View + Data View；`BEGIN DATA`/`END DATA` 须配对，`END DATA.` 独占一行 |
| `GET DATA /TYPE=ODS` | 导入 OpenDocument/Excel 表格 | 【推断】File → Import Data；`/TYPE` 须为首个，`/VARIABLES` 须放最后；`ASSUMEDSTRWIDTH` 易截断长文本，建议显式指定 |
| `GET DATA /TYPE=TXT` | 导入 CSV/定界文本 | 【推断】File → Import Data；`/DELIMITERS=` 用 `\t` 表示制表符；遗漏 `/FIRSTCASE=2` 会把表头当数据读入 |
| `IMPORT` | 读取系统/便携文件 | 【推断】File → Open；仅读取 .sav 等 PSPP 文件，不能直接读 Excel/CSV，后者须用 `GET DATA` |
| `SORT CASES` | 排序个案 | 【手册明示】Data → Sort Cases；`(D)` 降序、`(A)` 升序（默认）；只改变活动数据集，不改原 .sav |
| `SPLIT FILE` | 拆分文件分组输出 | 【推断】Data → Split File；`LAYERED` 合并于一张表、`SEPARATE` 各组独立表；持续生效至 `SPLIT FILE OFF.` |
| `SELECT IF` / `FILTER` | 选择 / 过滤个案 | 【推断】Data → Select Cases；`SELECT IF` 永久删除未选中个案，`FILTER` 仅隐藏、可 `FILTER OFF` 恢复 |
| `COMPUTE` | 计算新变量 | 【推断】Transform → Compute Variable；数值目标变量可自动新建，字符串目标变量须先以 `STRING` 声明 |
| `RECODE` | 重新编码 | 【推断】Transform → Recode；`THRU` 含端点，`ELSE` 须置于末组；省略 `INTO` 则就地改写 |
| `MISSING VALUES` | 定义缺失值 | 【推断】Variable View → Missing；数值至多 3 个离散值或一个范围；用户缺失默认在多数过程中被排除 |
| `VARIABLE LABELS` / `VALUE LABELS` | 变量标签 / 值标签 | 【推断】Variable View；`VALUE LABELS` 会清空已有值标签，追加请用 `ADD VALUE LABELS` |
| `FREQUENCIES` | 频率统计与图表 | 【推断】Analyze → Descriptive Statistics → Frequencies；`/HISTOGRAM`、`/PIECHART`、`/BARCHART`；对字符串变量不画直方图 |
| `DESCRIPTIVES` | 描述统计与 Z 分数 | 【推断】Analyze → Descriptive Statistics → Descriptives；`/SAVE` 写出 Z 分数新变量（如 Zheight） |
| `EXAMINE` | 探索性分析与箱线/正态图 | 【推断】Analyze → Descriptive Statistics → Explore；`/PLOT=BOXPLOT|NPPLOT|HISTOGRAM`；请求图形时自动做 Shapiro-Wilk 检验 |
| `CROSSTABS` | 交叉表与 χ² 检验 | 【推断】Analyze → Descriptive Statistics → Crosstabs；`/STATISTICS=CHISQ` 含 Pearson χ²、似然比、Fisher 精确等 |
| `MEANS` | 分组均值 | 【推断】Analyze → Compare Means → Means；`/CELLS=MEAN,STDDEV,SUM,MIN,MAX,…` |
| `T-TEST` | t 检验（单样本/独立/配对） | 【推断】Analyze → Compare Means → (One/Independent/Paired) Samples T Test；由 `TESTVAL=`/`GROUPS=`/`PAIRS=` 触发；独立样本自动含 Levene 方差齐性检验 |
| `NPAR TESTS` | 非参数检验 | 【推断】Analyze → Nonparametric Tests → …；`/CHISQUARE`、`/SIGN`、`/WILCOXON`、`/MANN-WHITNEY`、`/KOLMOGOROV-SMIRNOV` |
| `ONEWAY` | 单因素 ANOVA | 【推断】Analyze → Compare Means → One-Way ANOVA；仅处理单因素，`/POSTHOC=TUKEY` 等，`/STATISTICS=HOMOGENEITY` 做 Levene |
| `GLM` | 析因（双/多因素）ANOVA | 【推断】Analyze → General Linear Model → Univariate；PSPP 中双因素须走 GLM；`/DESIGN=` 用 `*` 连接交互项 |
| `CORRELATIONS` | Pearson 相关 | 【推断】Analyze → Correlate → Bivariate；`/PRINT=TWOTAIL SIG`；`/MISSING=PAIRWISE`（默认） |
| `REGRESSION` | 线性 / 多元回归 | 【推断】Analyze → Regression → Linear；`/DEPENDENT=` 必填；`/SAVE=PRED RESID`；缺乏 `/SCATTERPLOT` 等诊断子命令 |
| `GRAPH /SCATTERPLOT` | 散点图 | 【推断】Graphs → Legacy Dialogs → Scatter/Dot；一次调用只能画一种图 |
| `GRAPH /HISTOGRAM` | 直方图 | 【推断】Graphs → Legacy Dialogs → Histogram；`(NORMAL)` 叠加正态曲线；仅接受单一变量 |
| `GRAPH /BAR` | 条形图 | 【推断】Graphs → Legacy Dialogs → Bar；第二分类变量产生簇状条图 |
| `FREQUENCIES /PIECHART` | 饼图（唯一途径） | 【推断】Analyze → Descriptive Statistics → Frequencies → Charts；`GRAPH` 本身无饼图子命令，饼图只能走 FREQUENCIES |

### PSPP 当前未实现的过程

PSPP 并非 SPSS 的完整克隆，部分 SPSS 过程在 PSPP 中尚未实现。双因素或多因素方差分析不能依赖 `ANOVA` 或 `UNIANOVA`（二者均未实现），应改用 `GLM` 并在 `/DESIGN` 中写明交互项（如 `a*b`）。原始 GPL 自定义作图命令 `GGRAPH`、`IGRAPH`、`XGRAPH` 均不可用；茎叶图命令 `STEMLEAF` 不可用；SPSS 式的多格式导入命令 `GET TRANSLATE` 亦不可用。此外，手册还列出 `MANOVA`、`MULT RESPONSE`、`CURVEFIT`、`PPLOT` 等同样未实现。涉及上述过程时，应避免在教程中描述成 PSPP 可直接完成的操作，必要时应提示读者改用替代命令或手工处理，并明确说明"PSPP 当前不支持"。

## 附录 C · 练习数据与素材说明

本书各章的示例数据均为作者为演示语法而构想的虚构数据，仅用于说明操作步骤与输出解读，**不可用于任何真实研究或论文结论**。读者在练习时请始终将其视为教学素材，不要对数值本身做统计推断或外推。

GNU PSPP 官方手册随附了若干示例数据集，通常安装后位于 `/usr/local/share/pspp/examples` 目录，包括：

- `physiology.sav`：生理测量类示例（如身高、体温等）；
- `personnel.sav`：人事/员工类示例（如部门、职级等）；
- `repairs.sav`：设备维修记录类示例（如故障时间、维修时长等）；
- `horticulture.sav`：园艺/栽培类示例（如产量、处理分组等）。

这些文件同样是手册作者虚构的演示数据，仅用于熟悉命令，并非真实观测。读者可通过图形界面 File → Open 打开它们，或在语法中先用 `GET DATA`/`IMPORT` 读入后进行跟练。

若读者希望自建练习数据表，建议先在设计阶段确定字段，再录入或导入。一份典型的练习数据表可包含如下字段：

- 一个可作为个案标识的编号字段（如 `id`，numeric）；
- 1~2 个分组/分类变量（如 `group`、`sex`，建议定义值标签，例如 0=女性、1=男性）；
- 2~3 个连续型测量变量（如 `height`、`weight`、`score`，numeric，保留适当小数位）；
- 如需练习缺失值处理，可预留一个会用特殊值（如 999）标记的字段，并配套 `MISSING VALUES` 定义。

自建数据可在电子表格软件中先存为 ODS 或 CSV，再用 `GET DATA` 导入。导入 ODS 的语法要点：

```
GET DATA /TYPE=ODS /FILE='file.ods'
        /SHEET=NAME 'Sheet1'
        /CELLRANGE=FULL
        /READNAMES=ON
        /ASSUMEDSTRWIDTH=32.
```

导入 CSV/定界文本时改用 `/TYPE=TXT`，并以 `/DELIMITERS=` 指定分隔符（制表符用 `\t`），用 `/FIRSTCASE=2` 跳过表头；`/VARIABLES=` 必须放在最后，并显式声明各列类型与宽度，以避免长文本被截断或表头误读为数据。

需要特别注意区域设置带来的两个常见隐患。其一，在部分语言环境（locale）下，数值小数点分隔符为逗号 `,`，录入 `12,5` 可能被误读；教学与练习建议采用英文 locale，或在格式中显式指定 `DOT8.3` 等后缀以固定小数点为 `.`。其二，字符串宽度默认偏窄，导入含长文本的列时务必显式设置 `ASSUMEDSTRWIDTH`，否则内容会被截断。

## 附录 D · 进阶学习资源

GNU PSPP 是自由软件，其权威资料均以官方发布为准。建议读者将以下资源作为长期参考：

- **官方网站与手册**：GNU PSPP 项目主页提供程序下载、版本说明与完整手册（Texinfo/HTML/PDF 等格式）。手册按命令分节点组织，是核查语法、子命令与缺省值的唯一权威来源。
- **许可说明**：PSPP 程序本身以 GNU GPL（GNU General Public License）发布；其文档以 GFDL（GNU Free Documentation License）发布。读者可在遵守许可条款的前提下自由使用、修改与再分发。
- **社区与常见问题**：PSPP 的用户邮件列表、发行版打包渠道与项目缺陷跟踪系统汇集了常见问题（FAQ）与版本动态。遇到界面或命令行为差异时，优先比对所装版本与官方手册。

本书内容基于 PSPP **2.0.1** 左右版本编写，所引命令、子命令与缺省值以该版本官方手册为据。读者可在 `pspp` 文本界面启动时或 `psppire` 的关于对话框中查看具体版本号；命令行为与手册节点编号均可能随版本变化。需特别强调：PSPP 官方明确其仍处于"work in progress"（持续开发）状态，新版本可能增补命令、子命令或修正既有行为。**所有命令的精确写法与可用性，最终请以读者所安装版本对应的官方手册为准**；若手册与本书表述出现分歧，以官方手册为准。对尚未实现的过程（见附录 A），请勿期待在现有版本中直接可用。发现疑似缺陷时，可先在官方缺陷跟踪系统检索是否已有报告，再决定是否提交新报告，并附上可复现的语法与数据样例，以便维护者定位。
