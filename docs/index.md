## 关于 PSPP

PSPP 是由 GNU 项目维护的自由、开源统计分析与报表生成程序，句法与 SPSS 相近，
既可在图形界面（PSPPIRE）中操作，也能通过语法文件写出可复现的批处理脚本。

本站内容基于本地 `pspp.md`（英文手册）、`pspp-zh.md`（中文手册）与 `pspp-tutorial`（入门教程）
整理构建，事实锚定 GNU PSPP 2.0.1（gff8d3d）。
